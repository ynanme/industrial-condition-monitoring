# Industrial Condition Monitoring System

An end-to-end embedded condition monitoring system for industrial equipment.

The project aims to explore the design of a complete condition monitoring
system, from real-time sensor acquisition on an STM32 microcontroller to an
Embedded Linux edge gateway and cloud-based monitoring.

## Hardware

- STM32 NUCLEO-F401RE
- Analog Devices EVAL-ADXL355-PMDZ 3-axis accelerometer

## Status

- **V0 — STM32 foundations:** completed
- **V1 — ADXL355 sensor acquisition:** completed
- **V2 — Real-time acquisition and signal processing:** in progress
